# 視距無線電鏈路：頻率與通聯可達率

中英雙語解說動畫，10 個章節：自由空間路徑損耗、頻率項的來源、菲涅爾區淨空、中點速判與餘裕反推、多路徑衰落、植被與天氣、城市非視距與屋頂鏈路、地形情境，以及總結。比較低頻段（1350–2690 MHz）與高頻段（4400–5900 MHz）。

- `out/LOS-link-frequency-1080p.mp4`：1920×1080、30 fps 的 H.264 影片，中英字幕燒錄在畫面上
- `web/`：互動網頁（`index.html`、`engine.js`、`data.js`、`audio.mp3`）
- `SCRIPT.md`：完整的中英對照旁白腳本，附時間碼
- `script/script.json`：腳本原始檔（修改內容都從這裡改）

這個資料夾是獨立的一套流程，跟 repo 根目錄的第一支影片（電話信令 CAS / CCS）互不影響。

## 建置

需要環境變數 `GEMINI_API_KEY`（Gemini API 付費層）。在這個資料夾裡執行：

```bash
./build.sh
```

旁白是整份腳本用一次請求生成（聲音 `Sulafat`），再依句間停頓切回每一句，避免分段生成時聲音不一致。之後的時間軸、配樂混音和 MP4 都會依實際語音長度重新產生。沒有設定金鑰時，會做出只有配樂、字幕時間用估算的版本。

## 內容說明

影片中的數字都是套用公式的示範計算（例如 0 dBi 天線、無饋線損耗），不是任何裝備的實際規格。實際選頻還要考慮頻譜派配、干擾、傳輸量和裝備規格，並以鏈路預算工具與現地會勘確認。
